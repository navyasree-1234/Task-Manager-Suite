# Task Manager Suite

A full-stack task management application for creating, managing, and tracking tasks.

## 🔗 Links

- **Live Application:** https://task-manager-suite-frontend.onrender.com
- **GitHub Repository:** https://github.com/navyasree-1234/Task-Manager-Suite

- User registration and login
- Secure authentication
- Create tasks
- View tasks
- Edit tasks
- Delete tasks
- Dashboard
- Frontend and backend integration
